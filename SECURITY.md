# Политика безопасности

Не публикуйте уязвимость, токен, private key, VLESS URI, дамп базы или иной
конфиденциальный материал в issue, pull request либо логах.

Для сообщения об уязвимости используйте приватный канал владельца репозитория
или GitHub Private Vulnerability Reporting, если он включён. Укажите затронутый
commit/image, безопасные шаги воспроизведения и возможное влияние. Ответ
ожидается в течение 7 календарных дней; исправление, mitigation или статус
будут сообщены отдельно.

При подтверждённой утечке credentials немедленно отзовите и замените секрет,
проверьте access logs, создайте новый deploy и не включайте значение секрета в
постмортем. Исторический Git rewrite требует отдельного решения владельца.
